# Utility classes

Generated by `pragma-css` (`cargo run -p pragma-css --example classes_doc`); do not edit by hand.

Closed subset of Tailwind v4: same names, same effect. Any class not listed here is a
`pragma check` error. No arbitrary values (`w-[37px]`), no negatives (`-mt-2`). Custom classes,
tokens and dark mode: css.md.

## Notation

`{a,b}` = alternatives; `{,-a}` = no suffix or `-a`; `{1..12}` = integers.

- `S` spacing (n × 0.25rem; `px` = 1px): `0 px 0.5 1 1.5 2 2.5 3 3.5 4 5 6 7 8 9 10 11 12 14 16 20 24 28 32 36 40 44 48 52 56 60 64 72 80 96`
- `F` fractions: `1/2 1/3 2/3 1/4 3/4`
- `C` colors: `white black transparent current {neutral,primary,danger,success,warning}-{50,100,200,300,400,500,600,700,800,900,950}`
- Opacity on any color: `C/{10,20,30,40,50,60,70,80,90}` (e.g. `bg-primary-500/50`)

## Variants

- State: `group-hover:` `hover:` `focus:` `focus-visible:` `active:` `disabled:` (`group-hover:` reacts to a parent with `group`)
- Theme: `dark:`
- Responsive, mobile first: `sm:` ≥40rem, `md:` ≥48rem, `lg:` ≥64rem, `xl:` ≥80rem, `2xl:` ≥96rem
- Combinable; each variant at most once, one breakpoint max: `md:hover:bg-primary-600`
