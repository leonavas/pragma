One file: markup, script and style

A component is one .html file. A top-level let is state, a function is an action or a derived value, and {path} puts a value in the text. Check a task, add one, hide the done ones: each action assigns a variable and the runtime reapplies the bindings. No hooks, no virtual DOM.

Install

One Rust binary compiles, checks, serves and bundles npm packages: no Vite, no esbuild, no config. Building it needs Cargo; Node 22 or newer only runs your .server.js files.

Then pragma new my-app, cd my-app and pragma dev.

Start with the guide 
git clone https://github.com/leonavas/pragma
cd pragma
cargo install --path core/cli/crates/pragma-cli
pragma -V
pragma 0.1.0
