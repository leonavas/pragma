pragma, for your agent

Everything an agent needs to build with pragma, in files it reads without a browser. Human: copy the prompt, paste it into your coding agent and say what to build.

The prompt

Replace the brackets with your app. The agent reads the docs, installs pragma, creates the app and runs pragma check --strict until it passes.

Read https://pragma.leonavas.workers.dev/llms-full.txt and create a pragma app that [describe your app]. Install pragma first if the pragma command is missing. Follow the AGENTS.md that pragma new writes into the app, and finish with pragma check --strict at zero errors and zero warnings.

Install and create

One Rust binary. On Linux x64, run the installer or download the binary (.tar.gz). On other platforms, build from source with Cargo. Node 22 or newer only runs .server.js files.

curl -fsSL https://pragma.leonavas.workers.dev/install.sh | sh
pragma new my-app
cd my-app
pragma dev

Files for agents

Same content as the HTML pages, in markdown. No hidden text, nothing written only for agents.

  • /llms-full.txt: the app rules and every doc in one file. Start here.
  • /llms.txt: the index, in the llmstxt.org format.
  • /index.md: the landing page.
  • /agents.md: this page.

A request for / or /agents with Accept: text/markdown gets the markdown file instead of the HTML. One doc per file:

  • /docs/rules.md: the rules of every app (AGENTS.md). Read first.
  • /docs/structure.md: where each file goes, pragma.json.
  • /docs/syntax.md: HTML directives and blocks.
  • /docs/components.md: components, props, slots.
  • /docs/state.md: script, actions, derived values, stores.
  • /docs/routes.md: pages, router, head tags.
  • /docs/data.md: load, server actions, SSR.
  • /docs/overlays.md: modal, alert, dropdown.
  • /docs/css.md: styles and theme.
  • /docs/classes.md: every utility class.
  • /docs/webmcp.md: forms as agent tools, markdown for agents.
  • /docs/packages.md: npm packages.
  • /docs/performance.md: defaults and budgets.
  • /docs/logs.md: OpenTelemetry logs.
  • /docs/cli.md: commands and check rules.

WebMCP tools on this site

This page and the landing page expose these tools to agents in the browser, as declarative WebMCP forms. Humans use the same forms. The landing page also has add_task (its demo to-do list), and /examples/data has sign_guestbook.
