Four constraints, enforced by the compiler

Native

A page is an .html file. Its behavior is the .js file with the same name, its data the .server.js. No JSX, no virtual DOM, no framework between you and the platform.

routes/
  index.html
  shop/[id].html
  shop/[id].js
  shop/[id].server.js

Closed

A colon binds a value, a dot a class, an at sign an event, a dollar sign reads state. Conditions and loops are tags. Anything outside that list is a build error, not a convention.

<for task in $visible key=task.id>
  <li .done="task.done">
    <input type="checkbox" @change="toggle">
    <span :text="task.title"></span>
  </li>
</for>

Small

The starter page loads 8.8 kB of JavaScript, gzip, router and runtime included. Each page preloads only the modules it imports, and budgets in pragma.json fail the build when a page grows.

page     JS gzip
/         8.8 KB
CSS       4.1 KB
1 page(s)
dist/ built in 6 ms

Agent-first

Every app ships with AGENTS.md and its docs. pragma check answers with file, line, column, rule and fix, so an agent corrects itself in one pass instead of guessing.

  inline onclick is not allowed;
  use @<event>="action"
