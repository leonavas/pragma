What each page loads

Every page loads the runtime, boot-*.js: it runs the router and the bindings. Each route that has a script gets one chunk. Code that two routes use, such as like-button here, goes to a shared chunk.

A page with no script loads only the runtime. The page modulepreloads each chunk it runs.

pragma build
page     JS gzip
/        10.7 KB
/about   10.5 KB
/blog    10.7 KB
CSS       2.8 KB
3 page(s)
dist/ built in 31 ms
cd dist/client && find assets -name '*.js' | sort
assets/chunks/overlay-5e18fa36.js
assets/chunks/shared000-c4f1c28a.js
assets/core/boot-819b8b79.js
assets/routes/blog-217c6bf2.js
assets/routes/index-217c6bf2.js
grep -oE '<(link|script) [^>]*\.js"' about.html
<script type="module" src="/assets/core/boot-819b8b79.js"
grep -oE '<(link|script) [^>]*\.js"' blog.html
<link rel="modulepreload" href="/assets/routes/blog-217c6bf2.js"
<link rel="modulepreload" href="/assets/chunks/shared000-c4f1c28a.js"
<script type="module" src="/assets/core/boot-819b8b79.js"

overlay-*.js is the runtime code for modals, alerts and dropdowns. The runtime loads it with import() only when a page uses one, so no page here loads it.

Load your own code on click

Code that runs only after a click goes in a utils/ module. The action loads it with await import(). The build puts it in its own chunk, which the page does not preload and its size does not count.

A static import of the same module anywhere in the route puts it back in the route chunk. For npm packages, see Load a package on click.

pragma build
page      JS gzip
/         10.7 KB
/about    10.5 KB
/blog     10.7 KB
/report   10.7 KB
CSS        2.8 KB
4 page(s)

Rules that keep a page fast

  • Navigate with <a href>: the router prefetches links. A button that calls navigate() gets no prefetch.
  • Set width and height on every <img>, and loading="lazy" below the fold.
  • Make the skeleton the shape of the final content.
  • Give each <for> a stable key.
  • Return from load only the fields the page shows. Run independent requests with Promise.all.
  • Do not import large modules in lib/state/: every page that uses the store loads them.
  • Read the size table of pragma build after you add a package or a large module.
