The page module

A page gets state by adding a .js next to its .html: this page is routes/examples/state/index.js, and the markup on the right is written in the page itself, so $visitor and @click="forget" resolve against the page. In state and mount, ctx.el is the owner root, here <main data-page>.

$x on a page without a .js fails pragma check with html/invalid-root, and @x naming an action the owner does not export fails with html/unknown-action.

owner:

Derived values are getters

state(ctx) returns the initial object; :model writes the raw input into it. Everything computed from it (tip, total, the formatted labels) is a getter, rerun on every render, so there is nothing to keep in sync. HTML only reads paths: no expressions, so $perPersonLabel instead of a formula.

Sync and async actions, ctx.scope in a list

An action is (ctx) => …, called by @event. Inside a <for job in …>, ctx.scope.job is the item that was clicked, and mutating it is enough. An async action renders twice: once when its synchronous part returns (the button shows "Saving…") and again when its promise settles.

mount(ctx) for timers and global listeners

mount runs once after the first render and is only for external effects: timers, window or document listeners, observers. It returns the cleanup, which runs when the owner leaves the DOM (for a page, on navigation). Never fetch data in mount; that is what load is for.

ctx.update(fn) outside actions

The runtime renders after each action. Code that runs later, such as an interval callback or a detached promise, must change state through ctx.update(current => …), which mutates and schedules a render in the same microtask batch. Here the action starts the interval and the callback uses ctx.update; mount only returns the cleanup.

What ctx carries

ctx has $ (state plus read-only props), data, shared, params, query, page, log, update, call, navigate and open/close/confirm. In actions it also has event, el (the element with the @event) and scope. ctx.state and ctx.props do not exist and fail check with js/ctx.
