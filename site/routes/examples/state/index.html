Change state in place

State is tracked deeply: items.push(…) updates the list on the page. There is no need to copy the array.

Derived values

A value computed from state is a function: const total = () => tickets * 12. The markup reads it as {$total}, with no call, and it follows each change. In the script, call it: total().

Async actions

An async function updates the page before each await and again after it.

mount() and its cleanup

A function named mount runs in the browser after the page shows. Start timers and listeners there. The function that it returns runs when the reader leaves the page: stop them there.

Animation: frame

import { frame } from 'pragma' gets a service of the runtime. frame(step) runs step in the next animation frame. To animate, step asks for the next frame until it is done.

Wrapped handlers

A const that holds a function is a handler too. So a function made by debounce, from the npm package es-toolkit, works in @input="saveLater".

Services from 'pragma'

All runtime services come from import { … } from 'pragma'. The next pages show each one:

  • shared: stores (Stores).
  • params, query, navigate: the URL (Routing).
  • data, page, call: server data and actions (Data).
  • open, close, confirm: overlays (Overlays).
  • log: logs (Logs).

Script mistakes that check catches

These four mistakes give no error in the browser, only a wrong or stale value. pragma check stops each one and names the fix.

pragma check
orders.html:4 [js/top-level-data] `data` is read when the script starts, before the loader is done: read it inside a function
orders.html:6 [js/stale-derived] `label` reads `discount` once, when the script starts, and never updates: make it a function
orders.html:9 [js/derived-call] `empty` is a function (a derived value): call it in JS: `empty()`
orders.html:12 [js/dollar-in-script] `$orders` is HTML only; in <script> write `orders`

Coming from state(ctx)

  • export const state = () => ({ count: 0 }) is now let count = 0.
  • export const actions is now top-level functions; ctx.scope.item is an argument: @click="remove(item)".
  • ctx.update(fn) is gone: assign the let. ctx.$.prop is export let prop.
  • ctx.data, ctx.call and ctx.log come from 'pragma'.

The old API fails check with js/legacy-api, and each message names the replacement.
