OTEL_EXPORTER_OTLP_ENDPOINT
Base URL of an OTLP/HTTP collector. Records go to /v1/logs as OTLP JSON. Unset: one JSON line per record on stdout.
OTEL_EXPORTER_OTLP_LOGS_ENDPOINT
Full logs URL; wins over the base endpoint.
OTEL_EXPORTER_OTLP_HEADERS
Comma-separated key=value pairs sent to the collector, for an API key.
OTEL_SERVICE_NAME
Server service.name. Default: name from pragma.json. Client batches use the page hostname.
OTEL_RESOURCE_ATTRIBUTES
Extra resource attributes, deployment.environment=prod,service.version=1.4.0.
PRAGMA_LOG_LEVEL
Server minimum level: debug, info, warn or error. Default info in production; pragma dev sets debug, so server log.debug shows up while developing.
