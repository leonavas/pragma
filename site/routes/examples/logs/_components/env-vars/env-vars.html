OTEL_EXPORTER_OTLP_ENDPOINT
Base URL of an OTLP/HTTP collector; records go to /v1/logs. Unset: one JSON line per record on stdout.
OTEL_EXPORTER_OTLP_LOGS_ENDPOINT
Full logs URL; wins over the base endpoint.
OTEL_EXPORTER_OTLP_HEADERS
key=value pairs sent to the collector, for an API key.
OTEL_SERVICE_NAME
Server service.name. Default: name in pragma.json.
OTEL_RESOURCE_ATTRIBUTES
Extra attributes: deployment.environment=prod.
PRAGMA_LOG_LEVEL
Server minimum level. Default info; pragma dev uses debug.
