Script and text: {$name}

Each example on this page is routes/index.html, the home page of a new app. A <script> at the top of the page holds its values. A top-level let is state: a value that can change.

{$name} puts the value of name in the text. The $ says that the name comes from the script. Braces work in attribute strings too: title="Hi {$name}".

Events: @click

@click="add(1)" calls the function add of the script with the argument 1. The function assigns score, and the page shows the new value. No other step is necessary.

Without parentheses, @click="add" gives the function the DOM event. Any DOM event works: @input, @keydown, @submit.

Two-way binding: :model

:model="$name" keeps the field and name equal: typing changes name, and a new name changes the field. A checkbox gives a boolean, a number field a number.

Logic goes in a function

The HTML takes names, not code: {$name.toUpperCase()} is an error. Write a function in the script and use its name: {$loudName} calls loudName() on each render, so it always follows name.

Attributes: :attr

:disabled="$locked" sets the attribute from a value. true adds it and false removes it. This works for any attribute: :href, :title, :aria-expanded.

Class toggles: .class

.line-through="$done" adds the class line-through while done is true, and removes it when it is false.

:show hides, <if> creates

:show hides the element and keeps it in the page. <if $open> adds its content when open is true and removes it when it is false.

Conditions: <else-if> and <else>

After <if>, add <else-if> and <else>. One branch shows at a time. Each condition is a name: loading and failed are functions.

Lists: <for> and <empty>

<for task in $tasks key=task.id> repeats its element for each task. The key must be unique for each item. @click="remove(task)" gives the function the task of that row. <empty> shows when the list is empty.

What the compiler rejects

pragma check rejects all other syntax, and each error names the fix.
