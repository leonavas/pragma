Script and text: {$ship}

Each example on this page is routes/index.html, the home page of a new app. A <script> at the top of the page holds its values. A top-level let is state: a value that can change.

{$ship} puts the value of ship in the text. The $ says that the name comes from the script. Braces work in attribute strings too: title="Boarding {$ship}".

Events: @click

@click="hit(100)" calls the function hit of the script with the argument 100. The function assigns score, and the page shows the new value. No other step is necessary.

Without parentheses, @click="hit" gives the function the DOM event. Any DOM event works: @input, @keydown, @submit.

Two-way binding: :model

:model="$alias" keeps the field and alias equal: typing changes alias, and a new alias changes the field. A checkbox gives a boolean, a number field a number.

Logic goes in a function

The HTML takes names, not code: {$phrase.toUpperCase()} is an error. Write a function in the script and use its name: {$battleCry} calls battleCry() on each render, so it always follows phrase.

Attributes: :attr

:disabled="$locked" sets the attribute from a value. true adds it and false removes it. This works for any attribute: :href, :title, :aria-expanded.

Class toggles: .class

.line-through="$done" adds the class line-through while done is true, and removes it when it is false. Stack as many toggles as you need.

:show hides, <if> creates

:show hides the element and keeps it in the page. <if $lit> adds its content when lit is true and removes it when it is false.

Conditions: <else-if> and <else>

After <if>, add <else-if> and <else>. One branch shows at a time. Each condition is a name: purring and hungry are functions.

Lists: <for> and <empty>

<for slice in $slices key=slice.id> repeats its element for each slice. The key must be unique for each item. @click="eat(slice)" gives the function the slice of that row. <empty> shows when the list is empty.

What the compiler rejects

pragma check rejects all other syntax, and each error names the fix.
