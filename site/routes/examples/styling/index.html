Utilities and variants

The utility classes have the same names as in Tailwind v4. A variant such as hover: applies a class in one state. A class outside the list is a check error.

Tokens generate utilities

Each --color-<name> in lib/theme.css becomes a set of utilities: --color-accent gives bg-accent, text-accent and border-accent.

Component CSS, scoped by the build

A <style> in a component applies only to that component. The build adds a scope to each selector.

Values from state: :--name

There is no style attribute. :--progress="$progress" puts a value in a CSS variable, and the CSS reads var(--progress).

Light and dark theme

dark: utilities apply inside data-theme="dark". In an app, setTheme('dark') from .pragma/theme.js sets it on the page.
