Utilities and variants

The utility classes have the same names as in Tailwind v4. A variant such as hover: applies a class in one state. A class outside the list is a check error.

Tokens generate utilities

Each --color-<name> in lib/theme.css becomes a set of utilities: --color-accent gives bg-accent, text-accent and border-accent.

Custom classes and the cascade

A class used in many places, such as .btn, goes in @layer components in lib/theme.css. A utility beats a theme class, and the <style> of a component beats a utility.

Component CSS, scoped by the build

A <style> in a component applies only to that component. The build adds a scope to each selector.

Values from state: :--name

There is no style attribute. :--thrust="$thrust" puts a value in a CSS variable, and the CSS reads var(--thrust).

Values that change every frame

For a value that changes each frame (pointer, scroll, drag), set it in frame and use it only in translate, scale, rotate or opacity. These properties do not compute the layout again.

Enter and leave motion

The root of an <if> or <for> item gets data-entering when it comes in and data-leaving when it goes. The element stays until its CSS animation ends. Without an animation, it goes at once.

Light and dark theme

Theme toggle

theme() and setTheme() from .pragma/theme.js read and set the theme of the page. The choice stays for the next visit, and a first visit follows the system setting.
