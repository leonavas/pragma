One store, two components

lib/state/cart.js is the store cart: its let is state and its function is an action. Any component reads it as {shared.cart.count} and calls it with @click="shared.cart.add()". The two components here have no script.

A store lives in memory: it survives navigation, but not a reload.

A store in a script

In a script, import { shared } from 'pragma' gives the stores. Read the store like any value.

persist: state that survives a reload

export const persist = ['draft'] keeps draft in the browser storage, so it survives a reload. A second page, routes/notes.html, shows the same draft.
