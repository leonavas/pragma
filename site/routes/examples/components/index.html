A component is a file

routes/_components/counter/counter.html is the component <p-counter>. The pages in routes/ and its folders can use it. It has the same syntax as a page, but exactly one root element.

Each instance has its own state: two counters, two counts. A component in lib/components/counter/ is <c-counter> and works on every page.

Props: export let

export let sale = false declares a prop: a value that the page gives with an attribute, sale. The default decides the type, so sale="false" arrives as the boolean false. A missing attribute gives the default.

Object props: :prop="path"

An attribute is text. To give an object, bind it with a colon: :person="person". The component reads the object and does not change it.

Slots: content from the page

<slot> shows the children that the page puts in the tag. <slot name="actions"> shows only the children with slot="actions". The content of a <slot> shows when the page gives nothing.

A component without a script

Without a script, a component still reads its attributes as $label and $star. The compiler resolves it when it builds the page, so it sends plain HTML and no JavaScript.

A component that uses itself

A component can use its own tag. Put it inside <for> or <if>, so it stops when the data ends. Here the data is in routes/index.js: a page script can be a .js file next to the page, instead of a <script>.
