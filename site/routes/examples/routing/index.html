A file in routes/ is a page

routes/index.html is the page at /. routes/about.html is the page at /about. A folder adds a segment: routes/blog/index.html is /blog.

A page is a piece of HTML, with no <html> or <body>: the app adds them. <title> names the browser tab. A plain <a href> moves between pages, without a full reload. A URL with no file gets routes/_404.html, with status 404.

The root layout: routes/_layout.html

routes/_layout.html wraps every page: the header and the footer stay, and the page goes in <main data-page>, at <slot>. It has one <main data-page> with only the slot inside.

A layout has no <script>. It reads only shared, params and query, for example {shared.cart.count}. For behavior, put a component in it.

Params: [slug].html

routes/shop/[slug].html answers every URL of the form /shop/<anything>. The page reads that part of the URL as params.slug.

A layout for a folder

routes/shop/_layout.html wraps every page in routes/shop/ and its subfolders. The root layout wraps it in turn: root, then shop, then the page at the inner <slot>.

A folder layout has no <head> and no <main>: only its markup and one <slot>. A link to the current page gets aria-current="page", ready for CSS.

The query string: query

import { query } from 'pragma' gives the query string: ?tab=reviews is query.tab. A tab in the URL survives a reload and a shared link.

The current link for a query

aria-current is automatic only for a link without a query. For ?sort=price, bind :aria-current to a function that gives 'true' for the current link and false for the others. false removes the attribute.

Navigate from a script

navigate(url) opens a page from a script, like a click on a link. Use it after an action, for example after a save.

What the router does for free

  • Swaps only <main data-page> and the page's <title>, <meta> and <link>. Layouts stay mounted.
  • Prefetches a link on hover, on focus and when it scrolls into view.
  • Uses document.startViewTransition where the browser has it.
  • Scrolls to the top, restores the position on back and forward, follows #hash and moves focus to <main>.
