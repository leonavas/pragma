A form is a tool

toolname and tooldescription on a <form> make it a tool. Each field with a name is a parameter, and toolparamdescription tells the agent what to type.

toolautosubmit lets the agent submit without a click. Use it only on safe forms, such as add or search. The handler reads the fields with FormData.

Reply to the agent

event.agentInvoked is true when an agent submits. event.respondWith(promise) gives the agent the result as JSON. Call it before any await.

Reply with errors too, so the agent can try again. A reply can also come from a server action: see the guestbook.

CSS while an agent fills the form

:tool-form-active matches the form while an agent fills it, and :tool-submit-active matches its submit button. The starter styles both; this component sets its own style.

Forms that are not tools: notool

A form without toolname gets a warning. Add notool to keep a form away from agents: sign in, password, payment. The build removes the attribute.

What the check rejects

pragma check finds broken tools: a field without name, a bad toolname, a bound description, half a pair. toolautosubmit on a delete is a warning, and an error with --strict.

pragma check
orders.html:5 [webmcp/autosubmit] toolautosubmit on "delete_order" lets an agent run it without a user click: remove toolautosubmit from forms that delete, pay or send
orders.html:8 [webmcp/param-name] <input> in a tool form without name: add name="…" (it is the tool parameter)
orders.html:13 [webmcp/name] toolname "Find Orders" is invalid: use 1 to 128 characters of A-Z, a-z, 0-9, _, . or -
orders.html:13 [webmcp/dynamic] tooldescription must be static: write tooldescription="…" with fixed text, no : binding or {}
orders.html:14 [webmcp/param-description] <input name="customer"> has no description for agents: add toolparamdescription="…", a <label> or aria-description
orders.html:17 [webmcp/pair] <form> has tooldescription but no toolname: add toolname="verb_object" (the browser needs both)
4 error(s), 2 warning(s)

Turn WebMCP off

WebMCP is on by default. "webmcp": false in pragma.json turns off the webmcp/* checks for the whole app, and any tool attribute left is an error. To hide one form, notool is better.

No tools on any page.

Markdown for agents without a browser

An agent that fetches a page without a browser asks for text/markdown. Put a .md file in public/ at the route's path: public/pricing.md answers /pricing. Browsers still get the HTML.
