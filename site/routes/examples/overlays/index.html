Modal with @open and @close

@open="about-pragma" opens the overlay with that id and @close closes the one it sits in; neither needs a line of JS. <c-modal> takes id and title, a default slot and an actions slot. It closes on Esc, a click on the backdrop, the × button, any @close, and the browser's Back button.

Alert with await confirm(id)

import { confirm } from 'pragma', then await confirm(id) opens the alert and resolves with the value of the @close button that was clicked, or 'cancel' on Esc and Back. <c-alert> is a <dialog role="alertdialog">, so a backdrop click does not dismiss it. For a destructive action, put autofocus on the safe button.

Dropdown on the popover API

<c-dropdown> is a [popover] under its button, flipped above when there is no room below. It closes on an outside click, Esc, @close and Back, and it does not lock scroll. Items can combine @close with @click, and pass arguments: @click="sortBy('size')".

The label here is a dynamic prop, :label="$menuLabel": the dropdown has no script, so it reads the caller's derived function on every render.

Stacking, open and close

Overlays stack: Discard with an edited name opens an alert on top of the modal. Each open overlay pushes a history entry, so Back closes only the top one. Focus returns to whatever opened each layer, and the page behind stops scrolling while a modal or alert is open, with the scrollbar gutter reserved only if there was a scrollbar.

From a script, open(id) and close(id) from 'pragma' do what @open and @close do. Open overlays only in response to a user action, and never keep "is open" in state: the <dialog> already knows.

They are ordinary components

The three overlays ship in the starter as lib/components/modal, alert and dropdown: one .html each, with no script, that you can restyle like any other component. The behavior lives in core/overlay.js, which the build adds only to pages that contain a <dialog> or [popover].

  • Do not create a <dialog> or [popover] by hand, call showModal(), use window.confirm or role="menu", or import core/overlay.js yourself.
