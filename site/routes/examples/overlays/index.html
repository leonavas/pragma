Modal: @open and @close

<c-modal>, <c-alert> and <c-dropdown> come with a new app, in lib/components/. @open="briefing" opens the overlay with the id briefing. @close closes the overlay it is in. Esc and the Back button close it too.

Alert: await confirm(id)

import { confirm } from 'pragma'. await confirm('delete-prod') opens the alert and waits. It returns the value of the clicked button, or 'cancel' on Esc.

Dropdown

<c-dropdown> is a menu under its button. It closes on an outside click, Esc and @close.

Stacking, and close(id) from a script

An overlay can open another one. close('editor') from 'pragma' closes an overlay from a script.

Restyle and animate

A class on <c-modal> restyles it. To animate the close, style [data-leaving]: the runtime waits for the animation.

Do not write <dialog> or [popover] by hand, call showModal() or window.confirm, or use role="menu".
